# 뽀 가계부 이미지 자산
사용자가 제공한 원본 시트는 design/sheets에 보관한다. planner의 WebP는 시트에서 각 그림을 잘라 투명 배경을 유지한 파일이다.

| 원본 | 화면에서 사용하는 자산 |
|---|---|
| characters.png | hello (제목), app (파비콘), purse (빈 내역), seal (달력 무지출 도장·무지출 확인 버튼) |
| controls.png | add, edit, trash, prev, next, calendar, wallet, restore, cloud |
| planner/panel.svg, ribbon.svg, key.svg, bow.svg | 크기가 달라지는 패널, 제목 띠, 버튼 표면, 헤더 리본 |
| 기존 개별 SVG | 메모·이력·내보내기 등 보조 기능 아이콘 |

상단 앱 제목과 연월 선택 버튼에는 ㈜여기어때컴퍼니가 제공한 여기어때 잘난체 2를 사용한다. 공식 원본과 사용 가이드는 `public/fonts/Jalnan2.otf`, `public/fonts/Jalnan2-guide.pdf`에 보관한다. [제작사 배포 페이지](https://gccompany.co.kr/font)
